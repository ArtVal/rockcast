1. Обрезание краёв — поля 16px, фикс-колонка ▶, статус «Playing locally…» внутри плеера 2. Пуск / видно ли, что играет — ▶ всегда видна, крупная; играющая строка/карточка/hero с эквалайзером 3. Разнобой шрифтов — единая шкала 10.5 / 11.5 / 12.5 / 13.5 / 14 / 18(20) 4. Окно аккаунта — карточка с секциями, статус-чипы, разделённые «Обновить» / «Выйти»
