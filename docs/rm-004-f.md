The local loader verifies the manifest, catalogVersion, and canonical UTF-8/LF SHA-256 before
parsing the bundled snapshot. It never fetches a catalog at build or startup and does not use the
mobile extended SQLite catalog.

JSON overrides preserve the established precedence: ROCKCAST_STATIONS, executable directory,
working directory, then app-data directory. Overrides use stations.v1.json. schema-v1 stations use
their explicit stable IDs and primary stream for the unchanged Station.url playback, relay, and Cast
path; all streams remain on Station metadata.

RM-004-I: The temporary stations.txt transition adapter has been retired; user overrides now
require schema-v1 stations.v1.json.

RM-004-G updates the vendored JSON/schema/manifest only with the explicit offline
`release_sync.py sync rockcast ... --release <immutable-dir>` command. Use dry-run, review, then
verify; a corrupt or mismatched release is rejected. Neither build nor startup downloads a catalog.
No manual catalog-copy workflow is supported. A rollback selects a prior immutable release through
the same tool; the bundled verified baseline remains available when RockServer is stopped.
